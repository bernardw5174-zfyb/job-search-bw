# 企业甄别清单（国内版）

> 识别求职路上的"坑"，确保不浪费时间在不良企业上。投前查底 → 面试过程观察 → 入职前条款核实。
> 路线：信用系统 → 面试过程 → 人际网络 → 网络评价 → 合同条款。范式：甄别是防线不是洁癖。实现：五渠道核查清单。

## 适用场景

- 收到面试邀约，对公司不熟
- 小公司/初创，条件"好得可疑"
- 面试安排非常规（时间/地点异常）
- JD 已挂很久/投了没反应/岗位来源可疑（→ 触发幽灵岗位检测）

## 幽灵岗位检测（借鉴公开项目 career-ops Block G）

> 企业甄别查「公司主体正不正规」，幽灵岗位检测查「岗位本身是否还活着」——两者互补。幽灵岗 = JD 挂着但实际不招了（已招到人没撤 / HR 冲 KPI 挂的 / 岗位冻结）。

> 🆕 **关卡位置（2026-09-19）**：幽灵岗检测 = 单 JD 评估 **L0 最先**（岗位真实性预检，≤1 分钟）——幽灵岗投递价值归零，**否决就不跑任何评估**（人岗匹配再高也没意义）；公司级核检（五渠道核查：状态/动态/评价）在投递前（L3）。

**触发条件**：**每次看 JD 最先过（L0）**——不等到"投了没动静"才查（那是滞后触发，白吃评估成本）；JD 挂很久没反应 / 投了没动静 / 来源可疑时尤其要查。

| 信号 | 判据 |
|------|------|
| 帖子年龄 | 30 天内=正常，60 天+=可疑（角色类型可调） |
| apply 按钮 | 是否还 active（最硬的直接事实） |
| JD 技术细节 | 泛泛而谈 = 幽灵岗相关信号（也可能是写得差） |
| 重复发布 | 90 天内同岗重发 2+ 次 = 可疑 |
| 裁员新闻 | 查公司近期是否裁这个部门（注意时间/规模/部门） |

**伦理框**：信号只用于帮候选人把时间花在真实机会上，绝不当作对公司的指控；始终给出合理解释，让候选人裁决。

## 五渠道核查清单

### 1. 企业信用系统甄别（投前/面试前）

- **渠道**：国家企业信用信息公示系统 / 企查查 / 天眼查
- **查什么**：是否注册、成立日期、注册资本、规模大小、经营状态
- **判断**：注册资本估算规模；规模越大，培训和发展机会相对越多、福利越齐全。注册异常/成立时间短/司法风险高 → 谨慎

### 2. 面试过程甄别（收到邀约后）

**Red flags：**
- [ ] 被安排在非常规时间面试（晚上/周末/临时通知）
- [ ] 面试地点偏僻
- [ ] 面试中要求付钱、扣押证件、交个人信息/私人物件

> 出现以上任一条 → 追问面试通知人，收集更多信息再判断。付钱/扣证件直接拒绝，切忌侥幸心理。

### 3. 人际网络甄别

- 直接向面试官了解公司情况
- 找身边熟悉企业 HR、亲朋好友了解
- 寻求专业职业指导师帮助
- 从多方位了解公司整体运营情况和行业内发展情况

### 4. 网络评价甄别

- **渠道**：职友集、看准网、领英等
- **看什么**：曾经/现在在职员工的评价，重点看**承诺兑现情况**——小公司常见"面试条件好、入职不兑现"

### 5. 劳动合同条款甄别（面试成功/入职前）

- 要求公司提前准备好劳动合同，确认具体条款
- **核对**：工作时长、休息休假规则、规章制度是否完善、社保缴纳
- 条款不完善 = 权益保障风险信号

## 陷阱

- ❌ 只查信用系统不查口碑——注册正常不代表不坑
- ❌ 面试中"感觉好"就放松甄别——承诺要落到合同才作数
- ❌ 侥幸心理——"应该没事吧"是最贵的思维

## 与其他框架的衔接

- JD 拆解出"职能定位不清/薪资可疑"信号 → 触发本清单核查
- 面试中发现异常 → 记录进自己的面试复盘（面试线待发布）

## 来源与适配说明

1. **原方法论出处**：
   - 国内求职通用经验（公开可得：职业指导公开内容中的企业核查常识）；
   - 幽灵岗位检测借鉴 **career-ops**（公开 GitHub 项目）的 Block G 方法。
2. **本地适配改了什么**：
   - 信用核查渠道改为国内三件套：国家企业信用信息公示系统 / 企查查 / 天眼查（原方法论面向海外公司库）；
   - 口碑渠道改为职友集/看准网（国内员工评价平台）；
   - 新增劳动合同条款核查（国内劳动法语境：社保缴纳/工时/休假规则）。
3. **已证伪 / 已删除的部分**：无（本清单为常识性防线，未引入需证伪的假设）。
4. **适用边界**：本清单为经验性防线，置信度中等（confidence: medium）——未做系统化实证；幽灵岗位检测信号为方向性判据（career-ops 原方法为欧美岗位环境，国内平台的"apply 按钮活性"观测方式略异，使用者自行校准）。不构成法律意见，合同纠纷请咨询专业人士。

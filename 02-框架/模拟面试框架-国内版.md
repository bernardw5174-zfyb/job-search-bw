# 模拟面试框架（国内版）

> 按国内真实面试流程练习，不是美式 onsite。逐题出、逐题打分、绑定简历、Debrief 改进。
> 路线：按轮次练习 → 逐题打分 → 追问机制 → 复盘改进。范式：国内三轮面试模型。实现：题目绑定简历项目 + 追问 + 改进计划。

## 适用场景

- 面试前准备（拿到面试邀约后，或投递期持续练习）
- 复盘真实面试（把面试中答不好的问题拿来重练）
- 转型面试准备（技术→业务，需要回答"为什么转型"）

## 核心认知：国内面试不是美式 onsite

原方法论假设美式 onsite（5技术+3行为），国内完全不同：

| 维度 | 美式（原方法论） | 国内（本框架） |
|------|----------------|---------------|
| 流程 | 5 技术 + 3 行为 | 三轮：技术/业务面 → 业务/交叉面 → HR面 |
| 题型 | 独立问题 | 连续追问 + 项目深挖 + 情景题 |
| 追问 | 少 | **高频**：答案模糊必追问 |
| HR面 | 合规敏感区 | **必问环节**：离职原因/稳定性/薪资/规划 |

## 国内面试三轮模型

| 轮次 | 面试官 | 题型 | 特点 |
|------|--------|------|------|
| 技术面/业务面 | 业务负责人/技术负责人 | 算法+项目深挖+系统设计 | 连续追问，不是独立问题；深挖简历里写的每个项目细节 |
| 业务面/交叉面 | 跨部门业务方 | 情景题+案例分析+过往项目复盘 | 考"能不能干活"；会问"如果遇到XX情况你怎么处理" |
| HR面 | HRBP/HR总监 | 离职原因、稳定性、薪资期望、职业规划 | 国内必问，提前准备口径 |

## 模拟面试交互结构

1. **逐题出题，逐题打分** — 不一次出全部题目
2. **每题打分 /10 + "优秀候选人会怎么回答" + 一个改进点**
3. **追问机制** — 答案模糊时追问：
   - "能具体说说吗"
   - "实际结果是什么"
   - "为什么这么选"
   - "数字从哪来，口径是什么"
4. **从简历出题** — 题目绑定简历具体项目，不是通用题库。面试官一定会深挖你简历里写的每个数字和项目
5. **面试后 Debrief** — 总评 + 最弱回答 + 需练习的问题 + 改进计划

## 国内特有面试题类型（必须提前准备）

- **空窗期解释** — 简历不写，面试必问。准备口径：时间段、做了什么、为什么、现在为什么回归
- **年龄相关隐含问题** — HR 不会直接问但会评估稳定性。用"经验+稳定性+可投入度"回答，不回避年龄
- **"为什么从技术转业务"** — 转型者必问。准备从 0 到 1 的转型故事：发现了什么、为什么转、做了什么、结果如何
- **薪资期望** — 提前准备口径，参考市场价 + 底线 + 期望，不要现场算。谈判要点：
  - 先确认对方出价，再谈涨幅（"贵司这个岗位的预算范围是？"）
  - 用市场锚点：同岗同城薪资范围（猎聘/Boss 数据）
  - 不直接拒绝："这个数字和我预期有差距，我考虑一下" 留空间
  - 组合谈：base 不满意谈股票/奖金/签字费/级别，不单盯 base
  - 书面确认：口头承诺全部落到 offer letter
- **离职原因** — 不抱怨前东家，用"发展空间/方向匹配"框架回答

## 回答结构（STAR 变体）

国内面试官喜欢结构化回答，用四段式：

```
背景（Situation）：一句话说清楚业务场景
任务（Task）：你的目标/职责
行动（Action）：你具体做了什么（业务语言，不是技术细节）
结果（Result）：可量化的数字
```

**追问防线**：每个数字都要能扛住 3 层追问——数字从哪来？口径是什么？和你有什么关系？

## 陷阱

- ❌ 用美式面试流程练习（5技术+3行为）——国内是三轮，HR面是必问环节
- ❌ 练习通用题库——题目必须绑定自己简历的项目，面试官会深挖
- ❌ 答案不准备数字——追问"实际结果是什么"答不出来直接减分
- ❌ 不复盘真实面试——每次真实面试都是最好的练习素材，24 小时内复盘
- ❌ 空窗期/年龄/转型问题不准备——国内必问，临场发挥最差

## 与其他框架的衔接

- 面试官会深挖简历数字 → 复盘时用《简历诊断框架》检查简历是否有扛不住追问的表述
- 面试暴露的简历问题 → 回到《经历改写框架》修改
- 面试结果 → 写入私人工作区《面试复盘》，匿名化后进案例库

## 来源与适配说明

1. **原方法论出处**：
   - 美式 onsite 面试模型（公开方法论，常见于海外求职指南）——本框架的"反面参照"；
   - 薪资谈判要点：综合常见谈判方法论（公开内容）+ 国内 offer 场景。
2. **本地适配改了什么**：
   - 面试流程从"5 技术 + 3 行为"改为**国内三轮模型**（技术/业务面 → 业务/交叉面 → HR面），HR 面从"合规敏感区"改为"必问环节"；
   - 题型从"独立问题"改为"连续追问 + 项目深挖 + 情景题"；
   - 新增国内特有必问题型：空窗期解释、年龄隐含问题、转型故事、薪资谈判要点（先确认出价/市场锚点/不直接拒绝/组合谈/书面确认）；
   - 回答结构改为 STAR 四段式（业务语言，非技术细节）。
3. **已证伪 / 已删除的部分**：美式 5+3 流程直接套用国内 = 无效（国内追问机制完全不同），已整体替换。
4. **适用边界**：本框架的国内三轮模型与国内特有题型**仍属待验证**（假设注册表 #7 三轮面试模型 🔶 待验证、#9 薪资谈判要点 🔶 待验证——均未触发真实面试样本）；逻辑成立但缺实战复盘反哺，验证后回写本页。

# 简历诊断框架（国内版）

> 从"我的简历看起来完整"到"为什么 HR 不给我面试"——先诊断，再动手改。
> 路线：找问题 → 排优先级 → 验证卡点。范式：国内人工筛选思维（非 ATS）。实现：逐段扫描 + 信号检查。

## 适用场景

- 投了很多份简历，回复率低或 0 面试
- 拿到反馈"简历不错"但就是没下文
- 换方向求职，不确定现有简历是否匹配目标岗位

## 核心认知（国内 vs 美国差异）

| 维度 | 美国（原方法论假设） | 中国（本框架） |
|------|-------------------|---------------|
| 筛选方式 | ATS 自动解析 | 平台投递 + 人工筛选（Boss/猎聘） |
| 刷简历时长 | 30 秒 | **6 秒第一屏决策** |
| 格式问题 | 表格/列/特殊字符致命 | 几乎不是问题 |
| 关键卡点 | 关键词匹配率 | **第一屏信号 + 平台在线简历** |

**删掉 ATS 思维**：不要纠结格式、页眉页脚、特殊字符。聚焦内容和信号。

## 五步诊断流程

### 第1步：定目标

明确三件事，缺一不可：
- 目标岗位（具体 title，如"CRM负责人/客户增长负责人"）——**由用户提供（title＋行业＋资历），不要拿包内示例方向（会员运营/AI 应用）作预设选项**；示例材料仅演示流程
- 行业（如"日化/美妆/消费医疗"）
- 资历层级（JUNIOR / MID / SENIOR / LEAD）

> 没有目标的诊断是无效的。诊断报告必须绑定一个具体岗位画像。

### 第2步：第一屏信号检查（国内最重要）

模拟 HR 6 秒决策：**只看摘要 + 核心业绩前两条，能不能看出"这个人能带来生意"？**

自检问题：
- [ ] 第一屏有没有目标岗位的行业/职能关键词（如"会员生命周期、CRM、精准触达"）？
- [ ] 第一屏有没有量化结果（销售额/会员数/转化率）？
- [ ] 第一屏的叙事重心是业务价值还是技术实现？
- [ ] 如果删掉第一屏，简历还剩什么吸引人？

> 实战教训（已验证）：投递有响应、被要简历，但之后无下文 = **平台 profile 过关，完整简历全文没过关**。卡点通常在第一屏，不在正文。

### 第3步：逐段扫描

逐段检查，每段问"对目标岗位的 HR 来说，这段过关吗"：

| 段落 | 检查点 |
|------|--------|
| 摘要 | 是否前置目标岗位关键词？有没有定位句（"XX年XX领域经验"）？ |
| 核心业绩 | 是否 3 条不同维度？是否每条有数字？是否锚定目标岗位核心能力？ |
| 工作经历 | 最近 3 年是否占 50% 篇幅？每段是否"业务场景→角色→手段→量化结果"？ |
| 项目经验 | 是否独立成段？是否与工作经历有对应公司/时间覆盖？ |
| 技能/标签 | 是否有行业关键词 + 职能词 + 能力词的标签字段？ |

### 第4步：缺失信号检查

问：目标岗位 + 资历 + 行业期望看到，但简历里没有的信号？

- 关键词缺失（见《关键词情报框架-国内版》）
- 成就缺失（首创/独家/从0到1这类差异化钩子）
- 工具/平台缺失（行业常用工具、平台）
- 资质缺失（证书、行业经历）

### 第5步：Top 5 修复排序

按**影响力**排序，不是按难易度。每条附 before → after 示例。

排序逻辑：
1. 影响第一屏的（先改）→ 影响正文的（后改）
2. 影响 50% 岗位匹配的 → 影响 10% 岗位匹配的
3. 能立即改的（措辞/排序）→ 需要补数据的（要时间）

## 诊断输出格式

```markdown
## 简历诊断：[目标岗位] · [资历] · [行业]

### 🚨 致命问题（HR 6秒扫不到信号）
...

### 🔬 逐段诊断
**摘要：** ...
**核心业绩：** ...
**工作经历：** ...
**项目经验：** ...

### ❌ 缺失信号
...

### 🎯 Top 5 修复（按影响力排序）
1. ... (before → after)
2. ...
```

## 陷阱

- ❌ 不诊断就改写——先知道卡在哪，再动手
- ❌ 只改措辞不改结构——第一屏问题通常是结构问题（叙事重心错位），不是用词问题
- ❌ 追求"看起来完美"——诊断目标是"能不能进面试"，不是"简历漂不漂亮"
- ❌ 忽略平台在线简历——猎聘/Boss 的在线简历文本决定系统推荐和搜索命中，与附件 PDF 是两回事
- ❌ 用概数——诊断时标注"这里需要具体数字"比给个模糊建议有用

## 与其他框架的衔接

- 诊断出关键词问题 → 走《关键词情报框架-国内版》
- 诊断出表述问题 → 走《经历改写框架-XYZ国内版》
- 诊断出面试风险点（空窗期/年龄/转型） → 记入自己的准备清单（面试线待发布）

## 来源与适配说明

1. **原方法论出处**：
   - 国外源 hohowin resume-diagnoser（公开 GitHub 项目）——提供"ATS 筛选"视角的简历诊断思路；
   - 国内实战验证——第一屏 6 秒信号假设来自真实求职数据（详见假设注册表 #2）。
2. **本地适配改了什么**：
   - 删除 ATS 假设（国内平台无 ATS 自动筛，见下）；格式问题从"致命"降为"几乎不是问题"；
   - 核心卡点从"关键词匹配率"改为"第一屏信号 + 平台在线简历"（国内 HR 人工筛选 + 平台推荐机制）；
   - 新增"平台在线简历"检查（猎聘/Boss 在线文本决定系统推荐，与附件 PDF 是两套系统）。
3. **已证伪 / 已删除的部分**：ATS 假设（简历格式/解析影响筛选）**已被本地数据证伪**——国内 BOSS/猎聘等平台为人工筛选，无 ATS 自动解析，已从框架删除（假设注册表 #1）。
4. **适用边界**：本框架针对国内主流招聘平台（BOSS/猎聘/前程无忧）的人工筛选环境。若目标岗位以外企/海外流程为主（真 ATS 环境），格式与关键词检查需另行恢复。验证样本为个人实践数据（方向性信号，非统计结论）。

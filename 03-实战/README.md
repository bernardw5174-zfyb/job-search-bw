# 03-实战 — 参考货架（模板／示例／案例回流入口）

> **本目录是参考货架**（templates/示例/案例均为只读）：给你可复制的工具（模板）、可跑的演练材料（示例）、把脱敏案例回流传给包的入口（案例）。**你的实战产物不在本目录**——简历/投递记录/材料写 `00-raw/`，词表/知识页写 `01-知识/`（两者均被 `.gitignore` 保护，个人数据不入公开仓库）。

| 子目录 | 内容 | 可写性 |
|--------|------|--------|
| `templates/` | 简历模板／打招呼话术模板／投递记录表.csv | 只读参考（使用时复制到自己的目录） |
| `示例/` | 合成简历 + 合成 JD（虚构，练习用） | 只读 |
| `案例/` | 案例回流机制说明（首版不收录；回流治理链发布后启动） | 只读 |

**你的投递记录等个人数据**：独立使用时写 `00-raw/`（不入库）；作为 knowledge-growth 垂直包挂载时写 `vault/求职/03-实战/`。

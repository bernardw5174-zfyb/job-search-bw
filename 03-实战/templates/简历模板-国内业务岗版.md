# 简历模板（国内业务岗版）

> 结构参考《02-框架/简历定稿规则-国内版.md》（数字口径）与《02-框架/简历诊断框架-国内版.md》（第一屏信号）。替换 {占位} 为个人内容。

## 第一行（功能式 title）

```
{功能域描述，如：企业信息化 / 会员运营 / AI 应用落地} · {年限}+ 经验
```

## 摘要（第一屏，6 秒决策区）

```
{年限}年{领域}经验，{一句话定位：最强卖点}。{最亮项目：数字+结果}。{体系搭建/核心能力}，{差异化能力}。{级别信号：历任公司+职位序列}
```

> 摘要第一句承担级别信号（公司名+职位），第一行功能化后级别信息必须在此补位。

## 核心业绩（3 条不同维度，每条带数字）

```
- {维度1·业务创新}：{首创/独家项目}，{数字结果}
- {维度2·规模/体系}：{体系搭建}，覆盖{规模数字}
- {维度3·落地/提效}：{落地动作}，{量化结果}
```

## 工作经历（最近 3 年占 50% 篇幅）

```
### {公司名} | {职位} | {时间段}
- {业务场景/痛点} → {角色} → {动作（业务语言）} → {量化结果}
```

## 项目经验（独立成段，与工作经历对应）

```
### {项目名}（{时间段}）
- 定位：{项目做什么、解决谁的什么痛点}
- 角色：{方案设计+落地负责人}
- 结果：{可量化数字}
```

## 技能/标签

```
- 行业关键词：{行业/渠道词}
- 职能词：{岗位核心能力词}
- 工具/平台：{行业常用工具}
```

## 定稿检查（发布前逐条过）

- [ ] 每个数字扛得住 3 层追问（来源？口径？与我的关系？）
- [ ] 无跨口径对比（复购率≠留存率；单次ARPU≠月均ARPU）
- [ ] 行业参照已查证来源，查不到不引用
- [ ] 无"赋能/抓手/闭环/助力"废话词
- [ ] 无内部阶段术语/技术架构细节（HR 看不懂的一律不写）
- [ ] 不写 ROI（示例偏好）
- [ ] 附件 PDF 第一行功能式；平台在线简历"期望职位"写标准职位词
- [ ] 多方向简历硬数字一致（团队人数/预算/时间/门店数不打架）

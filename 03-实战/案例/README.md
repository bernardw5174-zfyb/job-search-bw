# 案例 — 案例回流机制（待启动）

本目录用于存放**脱敏、抽象的共性案例**——「案例是方法论的原料，不是方法论本身」。

## 首版状态

**首版不收录任何真实案例**：方法论贡献已浓缩进 `04-复盘/假设注册表-公开版.md`（如 #2 第一屏信号：首屏重构后响应率翻倍），案例文件是冗余展开；且作者求职期，"可识别身份 + 弱势信息"组合不值得为展示案例冒风险。案例叙事属**内容层**（账号文章/视频选题），不进代码包。

## 案例回流治理链（发布后启动）

```text
用户提交脱敏案例
  ↓ 案例登记（场景/输入/动作/结果/时间/是否允许公开）
  ↓ 标记"单案例观察"
  ↓ 与已有假设/规则对照
  ↓ 多案例支持 or 反例出现 → 提案升级规则
  ↓ 维护者裁决 → 更新方法论 + CHANGELOG
```

- 提交方式：GitHub issue（**脱敏后**），维护者审核
- 核心纪律：单案例观察（n=1）非统计证据；案例不得包含真实姓名/公司名/可反推细节
- 健康/离职谈判类案例**不走公开 issues**（隐私），需结构化脱敏贡献表单 + 人工审核门

# 第一次用 · 从这里开始（30 分钟跑通）

> 目标：30 分钟内完成"诊断 → 关键词 → 改写 → 模拟面试"四环中的核心两环（诊断 + 关键词），感受方法论怎么用。
> 不需要读完 7 份框架文档。先跑，再看。

## 你需要什么

- 本包（clone 或解压后）所在目录
- 一个兼容 Agent（WorkBuddy／Codex／Kimi Work／千问办公等；其他遵循 AGENTS.md／SKILL.md 约定的 Agent 也可尝试）
- 你的简历文本 + 1 份目标 JD（没有的话用 `03-实战/示例/` 里的合成材料）

## 5 步走

### 第 1 步（2 分钟）：认识结构

```
02-框架/        7 份方法论（诊断/关键词/改写/面试/投递/甄别/定稿）
skills/         4 个 Agent skill（可执行入口）
03-实战/示例/   合成简历 + 合成 JD（练习材料）
04-复盘/        假设注册表（每条方法的验证状态）
```

### 第 2 步（5 分钟）：跑第一次诊断

在 Agent 对话框里输入：

```
帮我诊断简历，目标岗位是会员运营经理，行业零售/快消。
简历在这：<你的简历文件路径或粘贴文本>
```

Agent 会按《简历诊断框架》输出：第一屏信号检查 → 逐段扫描 → 缺失信号 → Top 5 修复。

> 没有简历？用 `03-实战/示例/示例简历-会员运营经理-合成.md` + `示例JD-某连锁餐饮集团-会员运营经理-合成.md` 跑一遍。

### 第 3 步（10 分钟）：跑关键词对标

```
用这份 JD 对标我的简历，输出关键词缺失/埋没清单。
JD 在这：<JD 路径或文本>
```

得到：Top 关键词 + 缺失/埋没词 + 行动清单（先补 table-stakes → 前置埋没词 → 加趋势词 → 删废话）。

### 第 4 步（10 分钟）：挑 1-2 条经历改写

```
帮我改写核心业绩第一条：<粘贴原句>
```

Agent 按 XYZ 公式输出改写版 + 为什么 + 追问防线检查（数字口径）。

### 第 5 步（3 分钟）：验证

- 对照 `04-复盘/假设注册表-公开版.md`：你刚用的方法，哪些已验证、哪些是方向性信号——**本包卖的是验证机制，不是"已验证的完整体系"**
- 记住限定句：**务实版，不追求统计显著**；方向性信号、样本量小，不作统计结论

## 常见问题

| 问题 | 答案 |
|------|------|
| 要不要先读完 7 份框架？ | 不用。按需读：诊断时读诊断框架，改写时读改写框架 |
| Agent 说"不会"？ | 确认它读了根目录 `AGENTS.md` 与对应 skill；兼容性见 README |
| 材料放哪？ | 独立使用：放 `00-raw/`（你的简历/JD 是个人数据，本包 .gitignore 已排除，但**不要 push 到公开 fork**） |
| 改完简历投出去没回应？ | 按 `03-实战/templates/投递记录表.csv` 记录投递 → 积累数据 → 回填假设注册表（验证节奏见该表"验证节奏与停滞标注"） |

# 关键词情报

对标 JD 文本与简历，输出关键词行动清单。**本 skill 只走流程，分类与判定规则见框架文档。**

## 触发条件

- 用户说"看下这个 JD 匹配吗 / 我的简历有没有说 JD 的语言 / 关键词怎么补"
- 准备投新方向，不确定简历用什么词

## 前置检查

- 读 `02-框架/关键词情报框架-国内版.md`（关键词四分类、两轮筛选匹配度、封顶规则）
- 确认**场景**（语料门槛不同）：
  - **建词表／方向对标**（找岗位语言、补缺失词）→ 需 **10-15 份**同类岗位 JD 语料（框架第 1 步要求；不足则提示"先收集，或用现有语料做近似对标并标注")
  - **单 JD 评估**（这个 JD 匹配吗）→ 1 份 JD 即可（走硬性分层/覆盖率/证据矩阵）

## 流程步骤

1. 确认场景与语料：建词表 → 核对 ≥10-15 份 JD；单 JD 评估 → 1 份即可；**语料不足时不虚构词表**（按边界第 1 条处理，同时提示补齐）
2. 频率分析：提取高频词，按四分类标注（行业/职能/工具/AI 趋势）
3. 对标简历：逐词标 缺失/埋没/过时
4. 输出行动清单：先保 table-stakes → 前置埋没词 → 加趋势词 → 删废话词
5. 单 JD 评估场景：额外走硬性分层（A/B/C）→ 系统层覆盖率 → 人工层证据矩阵 → 封顶规则 → 投递建议
6. 提示平台双轨：改词同时打到在线简历与附件 PDF

## 产出位置

- 对话输出（关键词报告 / 单 JD 评估）
- 不自动写文件；用户要求时写用户工作区 `01-知识/_drafts/`

## 边界

- 不虚构关键词库——必须基于用户提供的真实 JD 文本
- 语言要求只提醒、不替用户砍岗（"流利英语"类由用户拍板）
- overqualified 信号只警示、不一票否决

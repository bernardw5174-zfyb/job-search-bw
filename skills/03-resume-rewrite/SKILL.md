# 经历改写

按 XYZ 公式把经历从"我做了什么"改写为"我带来了什么结果"。**本 skill 只走流程，公式与改写规则见框架文档。**

## 触发条件

- 用户说"帮我改这段经历 / 这条怎么写得有结果 / 简历改写"
- 诊断/关键词对标后进入改写环节

## 前置检查

- 读 `02-框架/经历改写框架-XYZ国内版.md`（XYZ 公式、改写规则、边界测试）
- 输入就位：原经历文本 + 目标岗位方向 +（建议）关键词清单（来自 02-keyword-intelligence）

## 流程步骤

1. 逐条拆解经历，标出：场景/角色/动作/结果 四要素
2. 套 XYZ 中国版结构改写（先业务结果、技术手段一句话）
3. 业务语言过滤：删 HR 看不懂的术语（技术架构/内部编号/阶段术语）
4. 关键词分层嵌入：table-stakes 词进第一屏、differentiating 词进业绩
5. Backtrack 边界测试：每条 bullet 模拟面试追问；⚠️ 档"拉伸"项主动呈报用户
6. 数字硬检查：每条数字追问来源与口径；缺精确数字的标"待补"

## 产出位置

- 对话输出改写版 + 每条"为什么"
- 用户确认后：写入用户工作区 `03-实战/`（投递版由用户另行生成 PDF）
- 待补数据清单单独列出

## 边界

- 不一次性给"最终版"——2-3 轮迭代是正常节奏，用户参与决策
- 不添加用户没写的内容（缺失信息用问题提出）
- 不改 title（违法/背调风险）；不编造经验（Interview Backtrack Test ❌ 档）
- 行业参照未查证不引用

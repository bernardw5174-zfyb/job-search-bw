# 模拟面试

按国内三轮面试模型（技术/业务面 → 业务/交叉面 → HR面）进行模拟面试。**本 skill 只走流程，面试模型与题型规则见框架文档。**

## 触发条件

- 用户说"模拟面试 / 帮我练一下 / 面试前准备"
- 真实面试复盘后重练薄弱题

## 前置检查

- 读 `02-框架/模拟面试框架-国内版.md`（三轮模型、追问机制、输出格式）
- 材料就位：简历文本 + 目标 JD（题目绑定简历项目，不用通用题库）

## 流程步骤

1. 确认轮次：技术/业务面 / 业务/交叉面 / HR面（按用户需求选）
2. 从简历+JD 生成题目（逐题出，不一次全给）
3. 逐题交互：用户作答 → 打分 /10 → "优秀候选人怎么答" → 一个改进点
4. 追问机制：答案模糊/缺数字时追问（能具体说吗/实际结果是什么/数字从哪来）
5. 国内特有题型覆盖：空窗期/年龄/转型/薪资期望/离职原因
6. Debrief：总评 + 最弱回答 + 需练习问题 + 改进计划

## 产出位置

- 对话输出（逐题 + Debrief）
- 复盘内容用户确认后：写入用户工作区 `04-复盘/面试复盘.md`

## 边界

- 不用美式 5+3 流程（国内三轮，HR面必问）
- 题目必须绑定简历具体项目（面试官会深挖每个数字）
- 薪资谈判只给策略，实际出价由用户现场定
